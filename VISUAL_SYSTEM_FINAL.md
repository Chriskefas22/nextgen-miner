# NextGen Miner — Final Background & Visual System

All dashboard views use page-specific futuristic SVG backgrounds with the same neon/glass design language.

## Backgrounds
- home.svg — Neo City Skyline
- dashboard.svg — Command Center
- miners.svg — Mining Hangar
- resources.svg — Resource Vault
- workers.svg — Workforce Hub
- transport.svg — Logistics Terminal
- wallet.svg — Financial Core
- deposit.svg — Deposit Gateway
- withdraw.svg — Withdraw Gateway
- exchange.svg — Crypto Exchange
- security.svg — Security Center
- admin.svg — Owner Control Room

## Visual rules
- Dark cinematic base with cyan/purple neon glows
- Glassmorphism panels with blur and subtle borders
- 5 miner families: Coal, Copper, Iron, Silver, Gold
- Miner levels 1–50 use level-specific artwork
- Locked cards use a dimmed artwork treatment and explicit status
- Resources, Workers, Transport each use level-specific artwork
- Mobile, tablet and desktop share the same visual language
