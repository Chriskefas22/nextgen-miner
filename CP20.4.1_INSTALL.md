# CP20.4.1 — Premium 3D Earth HUD Renderer

## Purpose
Replace the too-flat CP20.4 globe presentation with a higher-contrast hybrid renderer.

## Files
- `components/home/HolographicEarth.tsx` — complete renderer
- `components/home/HolographicEarth.module.css` — complete renderer styling
- `public/assets/home/earth-hologram-map.webp` — night-Earth texture

## Important
- No Supabase RPC changes.
- No economic SQL changes.
- No landing page changes.
- `HomeCommandCenter.tsx` does not need replacement if its existing `HolographicEarth` import remains.
- The renderer is presentation-only; metrics arrive from Home via props.

## Visual changes
- darker ocean / brighter city lights
- stronger atmospheric rim
- three orbital rings
- regional nodes with leader-line HUD cards
- central N control core
- live/paused state label
- hashrate / miner metrics from Home snapshot
- mobile node density reduced
- DPR capped
- reduced-motion support

## Manual install
Replace the two component files above and replace the existing Earth texture at the exact path.
