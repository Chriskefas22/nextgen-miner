# NEXTGEN MINER FINAL PROJECT RULES

1. User-facing currency = 💎 only.
2. Never display legacy currency names or a written currency label; use **💎** only.
3. Shop contains 12 miners matching the approved visual progression.
4. Every miner has levels 1–10.
5. Each upgrade increases hashrate by 15%.
6. Each next upgrade price increases by 35% from the previous upgrade cost.
7. Starter Keyboard activation is free; first paid upgrade starts at 💎100.
8. Minimum deposit = $0.01.
9. Minimum withdrawal = $1.00.
10. Cumulative qualifying top-up >= $1.00 is required before withdrawal.
11. Crypto-only payout methods.
12. Reward crediting must be server/database validated and idempotent.
13. Cloudflare Turnstile is preserved.
14. UI must remain distinct from LightningMiner.
15. Mobile-first responsive design.
