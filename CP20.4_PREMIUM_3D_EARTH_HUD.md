# CP20.4 — Premium 3D Earth HUD Engine

## Goal
Replace the low-detail procedural globe with a hybrid renderer: WebGL 3D sphere + local equirectangular Earth texture + Canvas HUD + live Supabase values passed from `HomeCommandCenter`.

## Files
- `components/home/HolographicEarth.tsx`
- `components/home/HolographicEarth.module.css`
- `components/home/HomeCommandCenter.tsx` (full file)
- `public/assets/home/earth-hologram-map.webp`

## Install
1. Replace `components/home/HomeCommandCenter.tsx` with this full file.
2. Replace `components/home/HolographicEarth.tsx`.
3. Replace `components/home/HolographicEarth.module.css`.
4. Add `public/assets/home/earth-hologram-map.webp`.
5. Do not modify the frozen landing components or Supabase economic SQL.

## Runtime design
- WebGL draws the Earth sphere and rotates it continuously.
- Local WebP provides detailed Earth surface/city-light texture without third-party runtime dependency.
- Canvas overlay draws orbit rings, live status, region anchors, and user snapshot metrics.
- Desktop gets restrained pointer parallax; mobile gets animation only.
- `prefers-reduced-motion` renders one stable frame and stops RAF.
- WebGL mesh is reduced on mobile.
- No Three.js dependency is added.

## Supabase boundary
The renderer receives only display-ready values from Home. It does not query, mutate, settle, recharge, or calculate economic state. Existing Home RPC calls remain authoritative.
