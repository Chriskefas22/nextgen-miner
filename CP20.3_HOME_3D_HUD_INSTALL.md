# CP20.3 — HOME LIVE 3D HOLOGRAPHIC HUD

## Purpose
Replace the static/empty Home hero visual with a lightweight, dependency-free WebGL holographic Earth HUD.

## Files to upload to GitHub
1. `components/home/HomeCommandCenter.tsx` — full replacement file. It imports and renders `HolographicEarth` inside the existing Home hero while preserving Supabase data/RPC behavior.
2. `components/home/HolographicEarth.tsx` — new WebGL + Canvas HUD renderer.
3. `components/home/HolographicEarth.module.css` — component styling.

No Supabase SQL/RPC changes are required.
No `package.json` dependency is required.
Landing page files are not changed.

## Visual/animation behavior
- True browser WebGL sphere rendering with procedural land texture.
- Continuous 360-degree Y-axis Earth rotation.
- Independent cyan/violet orbit motion and glowing nodes.
- Regional HUD labels track their projected globe positions.
- Gentle pointer parallax on desktop.
- Reduced geometry and lower DPR on mobile.
- `prefers-reduced-motion` freezes animation to a stable state.
- Canvas sizes are responsive via ResizeObserver.
- No GIF/video asset is required.

## Manual upload sequence
Upload/replace the three files above on `main` exactly at those paths. Vercel should deploy automatically.
