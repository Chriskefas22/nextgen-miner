### P0
1. `/wallet/deposit` is linked from the authenticated Topbar, but `app/wallet/deposit/page.tsx` does not exist.
   The route currently falls through the protected-route redirect when unauthenticated; once authenticated it has no page implementation.
2. `/shortlinks` UI advertises fake LIVE campaigns with static rewards even though the production database reports zero active shortlink campaigns.
   This is a user-facing integrity failure. No money movement was found in this route, but it misrepresents live earning availability.
3. Daily quest configuration is internally inconsistent:
   - `faucet_20` requires 20 claims/day.
   - Faucet is 5 Diamond per claim, daily cap 50 Diamond.
   - Therefore at most 10 claims/day are possible.
   - `offer_5`, `ptc_100`, and `shortlink_10` are enabled while the corresponding production activity sources are not live (0 active offers/PTC/shortlinks).
   These quests are not realistically completable in current production state.

### P1
1. `/dashboard/referrals` is not a private referral dashboard. It duplicates the public referral page and the authenticated CTA points back to itself.
2. Faucet UI converts a 300-second cooldown to `0 hours` using `toFixed(0)`, which is misleading.
3. Upgrade navigation uses `/miners?tab=upgrade`, but the audited miners page does not consume the `tab` parameter.
4. Leaderboard is hardcoded demo data and should not be presented as a live global ranking.
5. Notifications are hardcoded demo messages/timestamps rather than a live notification source.
6. Settings toggles are local/non-persistent and do not change application behavior.
7. Authenticated SECURITY DEFINER surface is broader than necessary (47 advisor findings); this belongs to CP20.2-C security hardening, not CP20.2-B.

## CP20.2-B scope
This patch deliberately limits itself to confirmed economic integrity issues:
- make quests completable/consistent with the current live provider state;
- reject upgrades against already-merged miner rows at the database boundary.

UI honesty fixes (Shortlinks, referral dashboard, faucet display, leaderboard, notifications, settings) remain queued separately so CP20.2-B does not become a mixed feature patch.
