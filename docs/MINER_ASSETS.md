# NextGen Miner visual pack

Starter Keyboard is intentionally removed.

Core: Basic CPU, Entry GPU, Gaming PC, Mini Rig, Performance Rig, Hydro Rig, Titan Rig, Nebula Station, Nuclear Reactor, Orion Core, Quantum Rig.

Premium: Dark Matter Engine, Solaris Array, Chrono Nexus, Galactic Core, Infinity Nexus.

The visual pack uses one cached high-resolution WebP master sprite plus 16 lightweight SVG crop wrappers. Each miner therefore appears as its own image URL while the browser downloads the master artwork only once. The SVG wrappers are used for clean browser scaling; the embedded artwork is raster and should not be interpreted as infinitely vector-detailed.
