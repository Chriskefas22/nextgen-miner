# CP20.5 — HOME NETWORK CORE / LANDING ENGINE PORT

This patch ports the proven Three.js Earth foundation from
`components/landing/NetworkCore.tsx` into the Home visual while keeping
LandingPage and all economic/Supabase logic unchanged.

## Replace exactly

1. `components/home/HolographicEarth.tsx`
2. `components/home/HolographicEarth.module.css`

No change to `HomeCommandCenter.tsx` is required because the current Home
already imports:

`import { HolographicEarth } from './HolographicEarth';`

and passes `metrics`.

## Important

The Earth texture is intentionally reused from the frozen Landing asset:

`/assets/landing/earth-equirectangular.webp`

Do NOT delete or rename that landing asset.

## What this changes

- Reuses the Landing's Three.js WebGL Earth foundation.
- Adds darker/high-contrast holographic Earth shading.
- Adds atmospheric shells.
- Adds 5 surface network nodes and routes attached to the globe.
- Adds three orbital rings.
- Adds a floating NextGen N core.
- Adds a 3D holographic platform.
- Adds restrained live HUD panels driven only by Home props.
- Adds desktop pointer parallax.
- Adds reduced-motion support.
- Uses lower geometry/DPR on mobile.

## What this does NOT change

- Supabase RPCs
- Settlement / claim
- Recharge
- Daily check-in
- Economic Capacity Guard
- Economic SQL
- LandingPage.tsx
- Landing NetworkCore.tsx

## Data boundary

The Earth renderer receives presentation-only metrics:

- asset
- status
- activeHashrate
- activeMiners
- dailyOutputUsd

It performs no Supabase calls and no economic mutations.

## Manual deployment checklist

1. Replace the two files above in GitHub `main`.
2. Wait for Vercel production deployment.
3. Hard-refresh the browser.
4. Verify `/dashboard` on desktop.
5. Verify `/dashboard` on Android/mobile.
6. Confirm Earth rotates 360 degrees.
7. Confirm nodes and route lines rotate with Earth.
8. Confirm live/paused state follows Home snapshot.
9. Confirm asset changes update the HUD asset badge.
10. Confirm no landing page files were modified.

## Expected visual direction

The Home hero should now use the same visual language as Landing:
real Earth texture + Three.js + atmosphere + nodes + routes,
with a richer command-center HUD layered around it.
