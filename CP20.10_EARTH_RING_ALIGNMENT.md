# CP20.10 — EARTH / RING / CORE ALIGNMENT

This patch follows a direct audit of the latest production screenshot.

## Verified deployment state

Vercel production is READY and is serving the `main` branch. The latest
production deployment is tied to GitHub commit `90a736146fb57d845b106f93ac4b06b2ed0ca886`.
That commit only adds the CP20.9 README; the HolographicEarth source is already
present in its parent history and is what the dashboard renders.

Therefore the remaining mismatch is visual architecture, not simply deployment
or browser cache.

## Concrete CP20.9 problems

1. The Earth was not actually rotated to place Europe/Africa in front.
2. The torus rings were tilted 64°, 63° and 56°, so they visually cut through
   the globe like random network lines.
3. The Earth and its atmosphere were centered at a different vertical level
   from the lower ring/platform system.
4. The mobile region labels were too close to the globe.
5. The central N DOM badge was aligned to the stage center rather than the
   raised Earth center.

## CP20.10 corrections

- Europe/Africa front-facing orientation is explicitly set to +100°.
- Earth, atmosphere, glow and surface nodes share the same vertical center.
- All four rings are horizontal, thin, and BELOW the Earth.
- Rings remain inside the same synchronized master transform.
- No city-to-city route lines exist.
- No random orbital arcs cross the Earth.
- Globe grid remains extremely subtle.
- N Core is moved to the actual Earth center.
- Region HUD labels are pushed outward on mobile.
- Existing Home/Supabase/economic actions are untouched.

## Replace exactly

- `components/home/HolographicEarth.tsx`
- `components/home/HolographicEarth.module.css`

Do not change:
- `HomeCommandCenter.tsx`
- landing files
- Supabase functions
- reward/settlement/recharge logic
