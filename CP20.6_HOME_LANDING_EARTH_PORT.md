# CP20.6 — HOME LANDING-EARTH PORT / RUNTIME STABILIZATION

## Root cause addressed

The Home Earth renderer was forcing a browser-created WebGL context into
`THREE.WebGLRenderer`. The proven Landing renderer does not do that.

CP20.6 uses the same initialization pattern as the frozen Landing engine:

`new THREE.WebGLRenderer({ canvas, ... })`

The renderer never promotes ordinary texture/network failure into a Home
fallback state. A valid 1x1 DataTexture is used until the Landing Earth texture
loads, so the WebGL scene remains alive during asset loading.

The animation loop is isolated from the application error boundary.

## Replace exactly

- `components/home/HolographicEarth.tsx`
- `components/home/HolographicEarth.module.css`

Do NOT change `HomeCommandCenter.tsx`.

## Visual source of truth

Earth texture:

- Landing-style direct Three.js renderer initialization.
- Reuses the frozen Landing Earth texture.
- Detailed Earth shader with darker ocean, land, coast, subtle city-light signal,
  atmosphere and fresnel rim.
- 3 synchronized Earth-surface network nodes and route arcs on mobile;
  5 nodes on desktop.
- Three outer orbital rings.
- Metallic holographic platform.
- CSS N core overlay.
- Live/paused + asset/hashrate/miner/output HUD driven only by Home props.
- Desktop pointer parallax.
- Mobile reduced geometry and DPR.
- Reduced-motion support.
- Safe texture-load failure.
- Safe renderer initialization failure.
- No Supabase calls or economic mutations inside the renderer.

## Expected critical behavior

1. Dashboard MUST NOT show the CP20.5.1 giant CSS-grid fallback under normal
   browser operation.
2. When WebGL works, the canvas is the primary Earth visual.
3. When the Earth texture is still loading, the globe remains rendered with a
   dark-blue placeholder instead of switching the entire component to fallback.
4. When the texture eventually loads, the real Landing Earth texture replaces
   the placeholder.
5. If WebGL truly fails, the renderer fails closed for this visual only; the
   Home page itself must remain available.
